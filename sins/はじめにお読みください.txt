■ sins式 髪質改善ストレート LP ― はじめにお読みください
==========================================================

このフォルダの中身をそのままサーバーにアップロードすれば公開できます。
特別なソフトやデータベースは不要です（HTML / CSS / JS / 画像だけ）。


1. フォルダの中身
----------------------------------------------------------
  index.html                 ページ本体（文章はここ）
  config.js                  ★ 設定ファイル（購入URL・動画・価格・LINE・講師名 など）
  css/style.css              デザイン（色・文字・余白）
  js/main.js                 動作（動画の視聴判定・スライダー・FAQ）※通常は触らない
  assets/                    画像（写真・アイコン）
  README.md                  制作者向けの詳しい説明（読まなくても大丈夫です）


2. サーバーへのアップロード
----------------------------------------------------------
  ・FTPソフト（FileZilla など）やレンタルサーバーのファイルマネージャーで、
    このフォルダの中身をすべて、公開したい場所にアップロードします。
    例）public_html/sins/ に入れると → https://あなたのドメイン/sins/ で表示
  ・フォルダ構成（css / js / assets）は変えないでください。
  ・アップロード後、ブラウザで表示して確認してください。
  ・公開URLが決まったら index.html の上のほうにある
      canonical / og:url / og:image
    の「https://o-arakawa.github.io/francdirect-dashboard/sins/」を
    実際のURLに書き換えてください（SNSでシェアしたときの表示に使われます）。


3. よくある変更のやり方（config.js を開いて書き換えるだけ）
----------------------------------------------------------
  ▼ 購入ページのURLを変える
      purchaseUrl: 'https://sins.base.shop',
      → 'https://～' の中身を新しいURLに

  ▼ 動画を差し替える・増やす（YouTube 限定公開がおすすめ）
      いま入っている動画（2本）
        1本目  https://youtu.be/fIy8MAHXpNM （髪質改善ストレート セミナー）
        2本目  https://youtu.be/zxhF30iWFDE （髪質改善 セミナー）
      1) YouTube に「限定公開」でアップロード
      2) 動画URLの youtu.be/ または v= の後ろの文字列（例 fIy8MAHXpNM）をコピー
      3) config.js の videos の src を書き換える
           videos: [
             { title: '髪質改善ストレート セミナー', note: '薬剤選定・施術の流れ（経営者目線パートあり）', type: 'youtube', src: 'fIy8MAHXpNM' },
             { title: '髪質改善 セミナー',           note: '経営者目線パートあり',                          type: 'youtube', src: 'zxhF30iWFDE' }
           ],
      ・title はタブに出る動画名、note はその下の小さな説明（'' にすると非表示）
      ・1本だけにするなら { … }, の行を1つ消す。3本目を足すなら同じ形の行を増やす
      ・動画が2本以上あると、動画の上に「1」「2」のタブが出て切り替えられます
      ・動画をいったん外すときは videos: [], にする（購入ボタンが最初から表示されます）

  ▼ 購入ボタンを出す条件を変える
      unlockRule: 'any',
      → 'any'   どれか1本を最後まで見たら表示（いまの設定）
        'all'   すべての動画を最後まで見たら表示
        'first' 1本目を最後まで見たら表示
      ・「最後まで」の目安は unlockAt: 0.9（90%）。飛ばした部分は数えません
      ・購入ボタンの下の説明文は、この設定に合わせて自動で変わります

  ▼ 価格の表記を変える
      price: '13,200円（税込）',
      → 空文字 '' にすると価格の行が消えます

  ▼ 公式LINE・お問い合わせ先を載せる
      lineUrl: 'https://lin.ee/xxxxx',
      contactUrl: 'mailto:info@example.com',
      → 空文字 '' のままなら表示されません

  ▼ 講師名・肩書き
      profile: { name: '菅原 寛人', romaji: 'Hiroto Sugawara', role: 'sins cosmetics ／ 現役美容師（sinsia）' },

  ▼ 受講者の声を載せる（実在の方のみ）
      testimonials: [
        { quote: '薬剤選定の基準がスタッフ間で揃った', salon: '〇〇（神奈川）', name: '〇〇 様' },
      ]
      → 1件以上入れると「受講者の声」セクションが自動で表示されます

  ▼ 施術例カード（ビフォーアフター）
      cases に 6件入っています（写真は assets/case1〜case6 の before / after）。
      ・title は写真の下の見出し（例 'ミディアム（黒髪）'）
      ・chart / thickness / history / recipe / reason に文字を入れると表示されます。
        空欄のままだと「動画内で解説」と表示されます。
      ・カードを減らすときは { … }, の行を消す、増やすときは同じ形の行を足して
        写真を assets に入れる（ratio は写真の 幅/高さ。正方形なら '1/1'）

  【注意】
  ・文字は半角の ' ' で囲む、行末の , は消さない、保存は UTF-8。
  ・書き換え後にページが真っ白になったら、config.js の書き間違い（' や , の抜け）が原因です。


4. 文章を変える
----------------------------------------------------------
  index.html をテキストエディタ（VS Code、メモ帳など）で開き、日本語の部分を書き換えます。
  ・「① ファーストビュー ここから」のようなコメントでセクションが区切られています。
  ・<span class="nb"> … </span> は「途中で改行させない」印です。消しても壊れません。
  ・<br> は改行です。<br class="show-desktop"> はパソコン表示のときだけの改行です。
  ・「縮毛矯正」という言葉は使わず「髪質改善ストレート」で統一しています。


5. 画像を差し替える
----------------------------------------------------------
  assets フォルダの同じファイル名で上書きします。
  ・「-600」「-1000」「-1600」のように末尾の数字が違うファイルは、同じ写真の大きさ違いです（施術例は -480 / -800 / -1200）。
    面倒な場合は、同じ画像を全部のファイル名で保存して構いません（表示は少し重くなります）。
  ・主な画像
      hero-*.jpg / hero-mobile-*.jpg   ファーストビューのモデル写真
      products-*.jpg                   薬剤4種の写真
      iron-*.jpg                       講師の写真（動画のプレースホルダーにも使用）
      counsel-*.jpg / apply-*.jpg / curlcheck-*.jpg / chart-*.jpg   施術工程
      case1〜case6-before-*.jpg / case1〜case6-after-*.jpg          ビフォーアフター（-480 / -800 / -1200 の3サイズ）
      seminar-*.jpg                    セミナーの様子
      og-1200x630.jpg                  SNSでシェアしたときの画像


6. 動作確認のコツ
----------------------------------------------------------
  ・購入ボタンの「視聴済み」の記憶を消したいとき
      ブラウザの「サイトデータの削除」または シークレットウィンドウで開き直す
  ・変更が反映されないとき
      Ctrl + F5（Mac は Cmd + Shift + R）で強制再読み込み
  ・パソコンで index.html をダブルクリックして開いても大まかな確認はできますが、
    YouTube 動画の視聴判定はサーバー上（http:// または https://）で確認してください。


7. 困ったとき
----------------------------------------------------------
  ・config.js を書き換えて壊れた → 配布時の config.js に戻してから、1か所ずつ変更する
  ・写真が表示されない → ファイル名（大文字小文字も）と assets フォルダの場所を確認
